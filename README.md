# Simon-Say-Game

::Project Description
The Simon Says Game is a simple memory-based game built using HTML, CSS, and JavaScript. The game tests the player's memory by generating a sequence of colors that the player must repeat in the correct order. As the level increases, the sequence becomes longer and more challenging.

::Features
Interactive color buttons
Random sequence generation
Increasing difficulty with levels
User input validation
Game restart after losing
Visual button flash effects

::Technologies Used
HTML – For creating the structure of the game
CSS – For styling and designing the buttons and layout
JavaScript – For game logic, event handling, and sequence generation

::How to Play
Open the game in your browser.
Click anywhere on the screen to start the game.
Watch the color sequence carefully.
Repeat the sequence by clicking the colored buttons in the same order.
Each correct sequence will move you to the next level.
If you click the wrong button, the game will end and you can restart.

::Game Logic
The system generates a random color sequence.
The sequence is shown to the user through flashing buttons.
The user must repeat the same sequence.
The game checks the user input with the generated sequence.
If correct → Level increases
If wrong → Game over
